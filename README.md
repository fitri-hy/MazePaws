# 🐾 MazePaws

Selamat datang di MazePaws! Game petualangan 3D yang seru dan menantang, tempat kamu bisa menjelajahi labirin, mengoleksi banyak peliharaan lucu, dan berpacu dengan waktu untuk jadi yang tercepat.

# 🌟 Tentang Game Ini

MazePaws adalah tempat di mana navigasi labirin bertemu dengan koleksi peliharaan. Kamu tidak hanya sekadar berjalan di labirin, tapi juga berpetualang mencari harta karun berupa koin dan permata untuk menambah koleksi peliharaanmu. Ada 20+ model peliharaan 3D yang bisa kamu dapatkan, mulai dari yang imut sampai yang langka!

> CATATAN: MazePaws menggunakan modul 3D (.glb) yang dimuat secara dinamis, Anda tidak bisa langsung membuka file index.html dengan cara klik dua kali (karena kebijakan keamanan CORS pada browser). Anda membutuhkan server lokal.
